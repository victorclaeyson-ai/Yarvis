# 1. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-14

## Context

Yarvis makes many choices with long-term consequences (speech engines, security model,
protocols). Contributors need to know *why* things are the way they are, not just *what*
they are.

## Decision

We record every significant decision as a short Architecture Decision Record (ADR) in
`docs/adr/`, numbered sequentially, using this template: Context, Decision, Consequences.
Superseded ADRs are kept and marked as such.

## Consequences

Decisions are reviewable in pull requests and discoverable later. Writing an ADR costs a
few minutes per decision.
